# Follow-up protocol

All jobs read the pinned Qwen3-8B-Base source revision `49e3418fbbbca6ecbdf9608b4d22e5a407081db4`. S01/R01/R02 use AutoRound PR revision `7985c1b0f4eef65fb717511668fda7e347e584c3`; R03 uses GPTQModel revision `ed96f2e04ec868b04f969733a242ce3b5bb7cb1e`. MatGPTQ remains at `0e5bd93bc53381f7195db870f5408ae04906bb3c`.

S01/R01/R02 pass pile-10k, 128 samples, 2048 tokens, batch 8, seed 42, FP16 model load and fake-QDQ export. R01/R02 fix the NeUQI search grid to 256 coarse/64 fine. R03 shuffles pile-10k with seed 42, tokenizes with the source slow tokenizer, prefers full 2048-token samples, concatenates short samples as a fallback, and records the selected token fingerprint. This matches the upstream AutoRound construction pattern, but sample selection need not be identical to J05. R03 quantizes with GPTQModel's Torch backend, batch 1, and materializes QDQ using its packed-weight decoder with a bias-inventory correction.

Before MatGPTQ evaluation, the runner checks the tokenizer/corpus SHA256 `8ffcee84dd4b684ec631cb52845e18c9c181ce6fdb8b26d65a4ffdc3`, 298862 scored tokens, 2048 nonoverlapping windows and FP16 inference settings. Each result has a pinned config hash, source checkpoint content identity, upstream SHA, checkpoint hashes, process log and marker. `encoding_complete.json` and `full.json` are independently resumable. An unmarked export can only be recovered when `quantization_process.json` records upstream exit code zero. A corrupted or unverified export is never silently overwritten.

The default full allocation is 1 GPU, 4 CPU, 12 GB host RAM and 12 hours. R03 uses the isolated GPTQModel environment; MatGPTQ evaluation stays in the original LP environment. The tiny R03 GPU smoke passed on AUS in job 53793, but it does not establish 8B resource feasibility. Capacity job 53833 showed the old QDQ and local offload workflow cannot fit these nodes. R03 now streams QDQ shards and uses a job-owned shared offload lease, but full quantization remains gated pending the new read-only preflight, largest-layer probe and manual review described in `r03_feasibility.md`. A failed full job writes `failure.json` rather than changing scientific settings.
